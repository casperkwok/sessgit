# countloc

统计目录下各类文件的代码行数，按行数从多到少输出。单文件，只用标准库。

## 用法

```
python3 countloc.py [目录] [--top N] [--exclude-comments]
```

| 参数 | 说明 |
| --- | --- |
| `目录` | 要统计的目录，默认当前目录 |
| `--top N` | 只显示行数最多的前 N 类；被截掉的几类合并成一行「其余 N 类」显示，合计仍是全量 |
| `--exclude-comments` | 剔除注释后再统计，只对认识的注释语法生效 |

```console
$ python3 countloc.py --top 3
类型       文件数  代码行数
---------------------------
.py             1         8
.js             1         7
Makefile        1         3
其余 3 类       3         8
---------------------------
合计            6        26
```

## 统计口径

- **代码行** = 去掉空行后的行数。加 `--exclude-comments` 后，整行都是注释的行（含块注释内的行、Python docstring）也不计入；行尾注释不影响该行。
- **首行 shebang 算代码行**，例如 `#!/bin/bash` 在 `--exclude-comments` 下仍计入 `.sh`。
- **排除** `.git` 和 `node_modules` 目录；二进制文件（UTF-8 解码失败）跳过。
- **分组**按扩展名；无扩展名时按文件名（`Makefile`、`Dockerfile`、`CMakeLists.txt` 等单独成组）。文件名为 `BUILD` 也单独成组。
- **排序**按代码行数降序，行数相同时顺序不保证稳定。

## 两个取舍

**一、注释识别是标记切分，不是真解析器。** 逐字符扫，只认标记，不建语法树：

- 认识的语法才剔：`#`（Python / Shell / YAML / Makefile 等）、`//` `/* */`（C 系 / JS / Go / Rust 等）、`--` `--[[ ]]`（SQL / Lua / Haskell）、`;`（Lisp 系）、`<!-- -->`（HTML / XML / Vue）。
- 不认识的类型（`.md`、`.json`、`.csv`、`.txt`）原样统计，不做任何剔除。
- 字符串字面量会整体跳过，所以 `"http://x/a#b"` 里的 `//` 和 `#` 不会误判成注释。
- 但 JS 正则字面量（`/\/\//`）、heredoc、未加引号的 CSS `url(http://…)` 仍可能误判 —— 这类行通常是既有代码又有"注释"标记，代码部分已经置位，所以影响一般落在"少算"而不是"多算"。
- Python 三引号只在行首（前面还没有代码）时按 docstring 剔除；`x = """…"""` 赋值里的三引号按字符串算，是启发式规则，不是语法层判断。

**二、只统计文本文件，二进制直接跳过。** 判断方式是"能不能用 UTF-8 严格解码"，所以 GBK 编码的源码会被当成二进制跳过（换编码得改 `open()` 的 `encoding`）。这样做是为了不引入 charset 探测依赖，代价是编码不是 UTF-8 的文件会静默消失，不进任何一列。
